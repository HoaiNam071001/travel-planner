# Travel Planner

Xem `CLAUDE.md` để biết đầy đủ bối cảnh, kiến trúc và roadmap của project.

## Chạy project

```bash
npm install
npm run dev
```

Mở http://localhost:5173

## Kết nối Supabase

1. Tạo project free tại https://supabase.com
2. Copy `.env.example` thành `.env`, điền URL + anon key (Project Settings > API)
3. Vào SQL Editor trên Supabase, tạo các bảng theo mô tả trong `CLAUDE.md`
